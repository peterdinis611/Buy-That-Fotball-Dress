# KIT VAULT

Storybook for the concourse / LED substitution-board UI. Use the **Lights** toolbar to switch Day and Night.

## Run

From `web/`:

```bash
npm run storybook
```

Opens on [http://localhost:6006](http://localhost:6006).

## What lives here

Presentational pitch pieces — jerseys, countdown, peg wall, house rules — without the live auction API.

Bid slips, watch mutations, and SignalR stay in the Next app.
