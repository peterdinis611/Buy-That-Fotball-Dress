# Web

Next.js App Router for KIT VAULT. Run the whole shop from the repo root:

```bash
./dev.sh
```

See the [root README](../README.md) for ports, seed logins, and the desk.

## Storybook

```bash
npm run storybook
```

[http://localhost:6006](http://localhost:6006). Stories sit next to the components (`*.stories.tsx`).
